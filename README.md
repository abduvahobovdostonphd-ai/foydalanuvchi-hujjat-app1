# Hujjat

Reklamasiz, obunasiz va hisobsiz ishlaydigan ofis fayllari ilovasi (Android).
Ilovada `INTERNET` ruxsati yo'q: fayllar qurilmadan chiqmaydi.

## Imkoniyatlar (0.2)

| Bo'lim | Nima qiladi |
|---|---|
| Bosh | Yangi hujjat/jadval yaratish, oxirgi fayllar |
| Fayllar | Tanlangan papkadagi fayllar, tur bo'yicha filtr, qidiruv |
| Hujjat | DOCX/ODT/TXT matnini ko'rish va tahrirlash, B/I/U, DOCX yoki TXT qilib saqlash |
| Jadval | XLSX/CSV ko'rish va tahrirlash, formulalar (SUM, AVERAGE, MAX, MIN, COUNT), XLSX saqlash |
| PDF | Sahifalarni ko'rish, ikki barmoq bilan yaqinlashtirish, ikki marta bosib kattalashtirish |
| Asboblar | PDF birlashtirish, PDF ajratish, kameradan skaner (PDF) |
| Yuborish | Har bir ochiq fayl va ro'yxatdagi fayl uchun "⇪" tugmasi: Telegram, pochta va boshqa ilovalar |

Slayd (PPTX/ODP) faqat matn ko'rinishida ochiladi. Keyingi versiyaga qoldi: izoh/imzo/matn qo'shish va PDF qulflash,
konvertor, rasmdan matn, parol qo'yish, rus va ingliz tillari, slayd muharriri.
Eski `.doc`, `.xls`, `.ppt` formatlari ochilmaydi.

PDF ajratish va birlashtirish natijasi sahifalarni rasm qilib yozadi: fayl hajmi kattaroq bo'ladi va matn belgilanmaydi.
