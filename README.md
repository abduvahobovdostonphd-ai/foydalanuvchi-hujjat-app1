# Hujjat

Reklamasiz, obunasiz va hisobsiz ishlaydigan ofis fayllari ko'ruvchisi (Android).
Ilovada `INTERNET` ruxsati yo'q: fayllar qurilmadan chiqmaydi.

## Hozirgi imkoniyatlar (0.1.0)

| Format | Holat |
|---|---|
| PDF | Sahifalarni ko'rish |
| DOCX, ODT | Matnni ko'rish (formatlash yo'q) |
| XLSX | Birinchi varaq jadval ko'rinishida (formulalar emas, hisoblangan qiymatlar) |
| PPTX | Har slaydning matni |
| ODS, ODP | Matn sifatida |
| TXT, CSV, MD, JSON | Ko'rish |
| DOC, XLS, PPT (eski) | Qo'llab-quvvatlanmaydi |

Tahrirlash, PDF asboblari va skaner hali yo'q. Ular keyingi versiyalar uchun reja.

## APK olish

1. Kod GitHub'ga yuklangach, **Actions** bo'limida "APK yig'ish" avtomatik ishga tushadi (taxminan 5-8 daqiqa).
2. Tugagach, **Releases** bo'limidagi "Hujjat (oxirgi APK)" ichidan `app-debug.apk` ni yuklab oling.
3. Telefonda faylni oching va "noma'lum manbalardan o'rnatish"ga ruxsat bering.

Agar yig'ish xato bilan tugasa, Actions ichidagi xato matnini ko'chirib yuboring.
